# ARIS 使い方
※詳しい使い方はまた別で制作する予定です。

## ログイン

1. ゲーム内で `/aris web` を実行
2. 表示された6桁コードを控える（5分間）
3. ブラウザで `http://<IP>:8080/` を開く
4. MCID とコードを入力してログイン

---

## 初期設定（設定ページ）

信号・分岐はワールド上のものが自動検出されるので、座標入力は不要。

1. **信号の灯式を設定** — マップ上の信号をクリック → 灯式を選択 → 保存
2. **分岐ポイントにN/R信号を紐付け** — 赤い四角をクリック → N信号・R信号を追加 → 保存
3. **区間を作成** — 「区間」の Add → 開始信号・終端（信号/分岐）・レールを設定 → 保存
4. **進路を作成** — 「進路」の Add → 通過区間・Nポイント・Rポイントを設定 → 保存

---

## 運行操作（操作ページ）

- 進路一覧の「**予約**」を押すと鎖錠される
- 列車が進路を抜けると**自動解放**される
- 手動で止めたい場合は「**解放**」を押す

---

## コマンド

| コマンド | 説明 |
|---|---|
| `/aris web` | Webログインコードを発行（OP Lv2） |
| `/aris reload` | 路線データを再読み込み（OP Lv2） |

---

## データ保存先
- `world/aris/data.json` — 路線データ
- `world/aris/sessions.json` — Webセッション
- `world/aris/cache/map.json` — 地図キャッシュ

バックアップは `world/aris/` フォルダごと取得してください。ツリーのフォルダ整理はブラウザの localStorage 保存なので、別端末では引き継がれません。
